## ⚙️ Installation & Setup (Localhost)

1. Install **XAMPP** or **WAMP**
2. Copy the project folder into: htdocs/
3. Start **Apache** and **MySQL**
4. Import the database:
- Open `phpMyAdmin`
- Create a database
- Import the `.sql` file (if provided)
5. Update database credentials in: config/config.php
6. Open browser and visit: http://localhost/project-folder-name/
